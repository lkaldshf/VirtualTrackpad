# 虚拟触摸板 · Virtual Trackpad

安卓上的单手操作小工具：屏幕右下角浮一个半透明圆盘，拇指在上面推，屏幕上有个圆点光标跟着走，走到哪点到哪。

灵感来自华为手机上的「虚拟触控板」，这里做成了**单指摇杆 + 触控板**的形态，并且额外加了「快速一刷 = 滑屏」的手势。

纯 `AccessibilityService` 手势注入方案，**不需要 root，不读取屏幕内容**。

## 手势

| 手势 | 效果 |
|---|---|
| 手指在圆盘上滑 | 光标跟手，滑多远走多远（滑出圆盘也照样算） |
| 快速一刷 | 光标当场锁住不动，松手后按刷过的实际距离滑一次屏 |
| 推到圆盘边缘顶住 | 光标开始持续加速跑，长距离不用反复擦手指 |
| 轻点圆盘 | 在光标处点击（连点两次 = 双击） |
| 双指轻点 | 在光标处长按（相当于右键菜单） |
| 双指上下滑 | 在光标处翻页，幅度比快刷更大 |
| 拖顶部横条 | 挪动圆盘；拖到屏幕左右边缘松手 → 收成小球 |

## 安装

去 [Releases](../../releases) 下载 APK 直接装，或者自己编译（见下方）。

最低支持 Android 8.0（API 26）。

## 首次使用（三步）

1. 打开 App，授权**悬浮窗**权限（画光标和圆盘要用）
2. 开启**无障碍服务**「虚拟触摸板 · 手势注入」——只用来在光标处发送点击/滑动，`canRetrieveWindowContent` 是关的，读不到你的屏幕
3. 回 App 点「开启触控板」

想从状态栏一键开关：下拉通知栏 → 点铅笔/编辑 → 把「虚拟触控板」拖进快捷开关区。

## 设置项

| 项 | 说明 |
|---|---|
| 跟手倍率 | 1.5x ~ 6.0x。手指走 1px，光标走几 px |
| 光标大小 | 14 ~ 44 dp |
| 摇杆大小 | 100 ~ 210 dp |
| 快刷滑屏 | 关掉后快刷只是挪光标，不注入滑动（纯触控板） |
| 震动反馈 | 轻点、长按、快刷锁定时给一下手感 |

## 实现要点

三个组件，各管一摊：

- **`TrackpadService`** —— 前台服务，挂两个 `TYPE_APPLICATION_OVERLAY` 悬浮窗：一个全屏 `FLAG_NOT_TOUCHABLE` 的光标层，一个圆盘面板。
- **`TrackpadAccessibilityService`** —— 只做 `dispatchGesture`，不读屏幕。点击、长按、滑动都从这里发。
- **`TrackpadTileService`** —— 状态栏快捷开关。

几个关键设计：

**快刷为什么要提前判决**：一开始是松手时才判断"这一下是刷还是拖"，结果整个滑动过程光标都被手指拖着跑，松手才滚屏 —— 手感上就是"手在动、光标乱飞、屏幕没反应"。现在改成边滑边算瞬时速度，一旦超过阈值当场锁定光标（用 45ms 时间常数的系数把它顺滑收回锚点），后续手指怎么动都不再驱动光标。

判定卡了四个条件防误判：按下后 420ms 窗口内、平滑速度 ≥ 320dp/s、位移 ≥ 6dp、且没在加速跑。慢拖超过 420ms 之后再快也不会被误判。

**注入不能和自己的触摸流打架**：手指还按在悬浮窗上时发 `dispatchGesture`，注入的事件会被派发回自己的窗口，光标就自己点自己了。所以所有注入都等手指抬起后再发，并且定位点压在圆盘上时先把圆盘临时藏起来（`injectSafely`）。

**贴边快刷不能截断路径**：光标贴在屏幕顶边时往上刷，如果按屏幕边界截短，长度直接变 0，白刷一场。正确做法是把整段路径整体平移进屏幕，保住长度。

**手指滑出悬浮窗后仍然收得到 MOVE**：Android 的 sticky touch target 行为，`event.x/y` 会变成负数。所以「滑出圆盘照样算距离」不需要放大窗口。

## 已知限制

- 系统设置、银行类 App 会拒绝显示非系统悬浮窗（`HIDE_NON_SYSTEM_OVERLAY_WINDOWS`），这是系统策略，绕不过去
- 注入依赖无障碍服务，被系统清掉或 App 被强停后需要重新开启一次
- 只测过 Android 8.1 / 9 / 15 的模拟器和真机，其他 ROM 可能有差异
